# Как показывать презентацию

## Основной вариант — HTML

Открыть `index.html` двойным щелчком в **Chrome**, нажать `F` для полного экрана.

Дек самодостаточный: шрифт вшит в `fonts.css` в base64, фотографии и логотип лежат
рядом. Интернет не нужен, работает прямо с флешки.

### Две темы

| Файл | Тема |
|---|---|
| `index.html` | тёмная — основная |
| `light.html` | светлая |

Светлая версия — не второй набор слайдов, а слой переменных `theme-light.css`
поверх той же разметки. Правка текста или фото попадает в обе темы сразу.

Светлая тема не инверсия. Три слайда остаются тёмными и работают как акценты:
**2, 4, 18** — фото на вылет с текстом поверх (белая шторка поверх снимка
читается как туман), **21** — чёрный экран, **26** — видеозаставка. Логотип и QR
на светлых слайдах подменяются на тёмные варианты автоматически.

Выбирать тему **до выступления**, а не на ходу: тауп `#877C6B` на светлом фоне
теряет контраст, поэтому в светлой теме он затемнён до `#6E6353`, и на проекторе
две версии выглядят по-разному.

### Управление

| Клавиша | Действие |
|---|---|
| `→` `↓` `Пробел` `PageDown` | вперёд (следующий шаг или слайд) |
| `←` `↑` `PageUp` | назад |
| номер и `Enter` | прыжок на слайд — если тайминг поплывёт |
| `Home` / `End` | первый / последний слайд |
| `F` | полный экран |

Кликер работает: он посылает те же PageUp/PageDown.

**Слайд 7.** Монтаж играет сразу, без надписей. По щелчку — «2 года / сотни встреч». Видео ~60 с, зациклено, без звука (автовоспроизведение в браузере так умеет только muted).

**Слайд 25** устроен в три такта. Сначала заставка играет чистой, без единой
надписи поверх — дайте ей отыграть хотя бы один круг, это 4 секунды. По нажатию
кадр уходит в расфокус и выходит «Не больше. Ближе.», следующим — QR и адрес
сайта. Видео зациклено и без звука, стартует с первого кадра каждый раз, когда
вы заходите на слайд.

Слайды с пошаговым появлением требуют дополнительных нажатий — их четыре группы,
и они синхронизированы с речью. Список — в `../PROMPT.md`, пункт 7.

### Проверить до выступления

1. Открыть на том ноутбуке, с которого будет показ, и прогнать дек до конца.
2. Разрешение экрана / проектора выставить 1920×1080.
3. Полный экран, курсор убрать с экрана.
4. Прогнать тестовый слайд на реальном проекторе: тауп `#877C6B` на холодной
   лампе уходит в серо-зелёный, а тёмные кадры проваливаются. Лучше увидеть это
   заранее.

## Запасной вариант — PDF / PPTX

`../inaya-sreda-2-goda.pdf` — тёмная тема, 76 страниц на 26 слайдов.
`../inaya-sreda-2-goda-light.pdf` — светлая, столько же страниц.
`../inaya-sreda-2-goda-light.pptx` — светлая в PowerPoint: каждый шаг
отдельный слайд 16:9, картинка на весь экран (как в PDF). Текст внутри
не редактируется — это запасной показ, не рабочий макет.

Разница 76 vs 26 не ошибка: пошаговые появления в запасных файлах не живут,
поэтому **каждый шаг анимации выгружен отдельной страницей**. Слайд 21
с паузой между двумя репликами — это три страницы: пустой чёрный экран,
первая реплика, вторая. Так драматургия пауз сохраняется и на резервной версии.

Пролистывать стрелками в любой программе для PDF или в PowerPoint.

## Пересборка

```
python3 grade-photos.py          # единый грейд фото из scenario-photos/ в deck/img/
```

PDF пересобирается из HTML. Для локального просмотра сначала
`python3 -m http.server 8787` из каталога `deck/`, затем:

```
CHROME='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome'

"$CHROME" --headless=new --no-pdf-header-footer \
  --print-to-pdf=inaya-sreda-2-goda.pdf \
  --virtual-time-budget=30000 \
  'http://127.0.0.1:8787/index.html?print'

"$CHROME" --headless=new --no-pdf-header-footer \
  --print-to-pdf=inaya-sreda-2-goda-light.pdf \
  --virtual-time-budget=30000 \
  'http://127.0.0.1:8787/index.html?print&light'
```

Параметры URL: `?all` открывает слайд со всеми раскрытыми шагами — удобно для
съёмки превью, `?light` включает светлую тему, `?print` даёт раскладку для PDF.
Комбинируются через `&`.

## Что ещё не подставлено

Плейсхолдеров на экране больше нет. QR на сайт стоит на финальном слайде. Генерация:

```
python3 make-qr.py https://inayasreda.ru/ deck/qr-site.png
```


Стоковые фото в дек не ставились принципиально: его сила в том, что на снимках
настоящие люди из зала, которые себя узнают.
